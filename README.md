# LuffyGame

**Игра для подготовки к ВПР по географии 5 класса**  
Сюжет: команда пиратов *One Piece* плывёт по четырём морям и Гранд-Лайн.

**Стек:** JavaScript + HTML5  
**Опционально:** [Wick Editor](https://www.wickeditor.com)

## Авторы

- Владимир Лаптев, Дмитрий Пикулин, Ярослав Костюков  
**Куратор:** Воронцов Николай Витальевич

## Как запустить

1. Code → Download ZIP  
2. Откройте **index.html** в браузере

Ничего устанавливать не нужно.
